# Third-party notices

## Mekanism GUI textures

The machine screen textures listed below come from Mekanism
(<https://github.com/mekanism/Mekanism>, version 10.7.19 for Minecraft 1.21.1) and were renamed. Some were split
into several sprites (button states) and received `.mcmeta` GUI scaling metadata. Files marked *modified* were
edited by hand; all other screen sprites and icons of this mod were drawn from scratch for it and are not listed.

All files are under `src/main/resources/assets/dimensionalfluxminer/textures/gui/sprites/`.

| File in this mod | Original file |
| --- | --- |
| `button/disabled.png`, `button/normal.png` | `gui/button.png` |
| `slot/normal.png` | `gui/slot/normal.png` |
| `slot/output.png` | `gui/slot/output.png` |
| `slot/extra.png` | `gui/slot/extra.png` |
| `slot/output_warning.png` | `gui/slot/output_warning.png` |
| `slot/overlay_check.png` (modified) | `gui/slot/overlay_check.png` |
| `icon/side_config.png` (modified) | `gui/configuration.png` |
| `icon/upgrade.png` (modified) | `gui/upgrade.png` |
| `icon/sorting.png` (modified) | `gui/sorting.png` |
| `icon/clear_sides.png` (modified) | `gui/button/clear_sides.png` |
| `icon/auto_eject.png` (modified) | `gui/button/auto_eject.png` |

The tab colors, text colors and route colors used by the screens follow the same project's GUI color maps.
